# TapDay: Daily Log

The public pages for TapDay, an iPhone app for logging everyday activities in 1–3 taps:
- https://toan-vo-ngoc.github.io/TapDay-Daily-Log/privacy/ (privacy policy)
- https://toan-vo-ngoc.github.io/TapDay-Daily-Log/support/ (support)

Plain static HTML for GitHub Pages: no build step, no scripts, no external requests.

The privacy policy's source is `documents/app-store/privacy-policy.md` in the app repo. Change that file and `privacy/index.html` together, word for word.
